# Viet-Theo-Bridge

## Vai trò

- **Web**: Mở trình duyệt + danh sách CSV (IndexedDB `video-affiliate-manager`)
- **Extension**: Số SP / Delay + nút **Gửi**
- **Lấy cookie**: từ tab Quản lý người dùng → nút chìa khóa → mở login Shopee, điền user/pass, lưu cookie về web

## Cài

1. Web → Tải extension → Load unpacked
2. Reload extension sau mỗi lần cập nhật (cần bản **1.5.2+** cho lấy/gắn cookie)

## Dùng — Lấy cookie

1. User phải có **Username** + **Mật khẩu**
2. Bấm nút chìa khóa (Lấy cookie) trên dòng user
3. Hệ thống mở **Chrome local** → login Shopee → lưu cookie vào tài khoản **và gắn vào Chrome local**
4. Nút máy tính (Gắn local): gắn cookie sẵn có của tài khoản vào Chrome local
5. Nếu hiện captcha slide puzzle → **dừng**, không bypass
