# Viet-Theo-Bridge

## Vai trò

- **Web**: Mở trình duyệt + danh sách CSV (IndexedDB `video-affiliate-manager`)
- **Extension**: Số SP / Delay + nút **Gửi**

## Cài

1. Web → Tải extension → Load unpacked
2. Reload extension sau mỗi lần cập nhật

## Dùng

1. Web: chọn Market → **Mở Trình duyệt**
2. Affiliate: tìm kiếm / lật trang
3. Extension: chọn Số SP / Delay → **Gửi CSV**
4. Web: danh sách CSV hiện ra (ID + thời gian) — xóa từng dòng / xóa tất cả
