Shopee Scrape Agent — macOS (MacBook)
====================================

1. Cài và mở GemLogin Desktop (bản Mac nếu có).
2. Lần đầu macOS chặn app chưa ký — chạy trong Terminal:
     cd thư-mục-giải-nén
     chmod +x BatDau.command ShopeeScrapeAgent-macos-*
     xattr -cr .
     ./BatDau.command
   hoặc chuột phải BatDau.command → Open.
3. Mac Intel / Apple Silicon (M1/M2/M3 qua Rosetta): ShopeeScrapeAgent-macos-x64
4. Giữ cửa sổ Agent mở → web Cào dữ liệu.

http://127.0.0.1:17890

Fallback: cài Node.js rồi: node agent.js
