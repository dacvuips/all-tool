# Workflow development
---
## Cài đặt npm package
> npm install

## Build code typescript
> npm run watch-ts

code javascript sẽ được generate ra tại thư mực _/dist_

## Build code giao diện
> npm run next:build

code giao diện sẽ được generate ra tại thư mục _/next/.next_

## Start server javascript
> npm run watch-node

----
## Cáu hình Hot reload Code giao diện
- Truy cập file .env
- Bổ sung cấu hình NEXT_DEV_MODE=true
